OpenDuo

Debian 13 on a mainline Linux kernel for the Microsoft Surface Duo 2. The project, its documentation and the install guide live at github.com/Andy1210/OpenDuo (install, updates).

The apt repository

This site serves OpenDuo's signed package repository, apt/ (suites stable and testing, arm64). An OpenDuo phone uses it already: Settings > Updates. Its public key is apt/openduo-archive-keyring.asc, fingerprint:
